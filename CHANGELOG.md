## [0.0.1] - 2026-03-25

### Added

- Initial release
- Syntax highlighting for `.lass` files using TextMate grammar
- Language configuration for bracket matching, comment toggling, auto-closing pairs
- Support for Lass two-zone model (JavaScript preamble + CSS zone)
- Highlighting for all Lass symbols: `$param`, `{{ }}`, `@{ }`, `@(prop)`, `//`, `---`
